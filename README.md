# Sailwind Food Preservation

A planned BepInEx mod for Sailwind that makes smoking and drying speed configurable by broad food category. Its default multipliers will preserve vanilla progression.

Development is in the investigation stage. There is no playable build yet.

## Compatibility

BetterFishing changes stove and smoker efficiency. If both mods are installed, preservation rates may reflect both sets of changes; combined behavior needs in-game testing.
